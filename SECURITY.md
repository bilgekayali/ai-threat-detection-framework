# Security policy

## Supported version

Security fixes are applied to the latest version on the main branch.

## Reporting

Do not open a public issue containing credentials, personal data, exploit details from a
real environment or confidential security architecture.

Use GitHub private vulnerability reporting when it is available for this repository.
If private reporting is unavailable, contact the maintainer privately through the
[LinkedIn profile](https://www.linkedin.com/in/bilge-kayali-9a1232149/) before
disclosing sensitive detail.

Include the affected version, reproduction steps, impact and a suggested mitigation
when possible. Do not test a report against systems or data you do not own or have
explicit permission to assess.
