# v1.0.0 — Stable research reference

This owner-authorized GitHub Release freezes the six-symbol public Python API,
the `ai-threat-eval` and `ai-threat-generate` commands, five Draft 2020-12 schemas,
and the 1,000-row synthetic dataset identified by `release/release-contract.json`.

The immutable `v1.0.0` tag identifies the exact tested commit. Publication waits
for successful latest CI, CodeQL and Stable Release Gate runs on that same current
`main` SHA. CI covers Python 3.10, 3.11 and 3.12. The release gate verifies frozen
fingerprints, dependency SBOM generation, wheel build and clean-wheel evaluation.
No package-index publication, container publication or deployment is authorized.

## Included

- Strict synthetic input validation and a documented rule baseline.
- Chronological train/holdout separation, random-forest and blended evaluation.
- Brier score, partition labels, runtime versions and analyst-facing reason codes.
- Scored alerts, feature importance, evaluation report and artifact-hash manifest.
- Model/dataset cards, compatibility policy and threat-model documentation.

## Boundaries

Stable refers to the package/API and reproducible research contract only. Synthetic
metrics do **not** establish real detection performance, production readiness,
regulatory compliance, certification, control effectiveness or authorization for
autonomous containment. There is no live SIEM/XDR integration or real system data.
Human triage remains required. Owner approval is not independent security review;
live repository-governance enforcement is not claimed.
